# Engineering Knowledge Base

A personal, continuously evolving collection of technical research, experiments, and explanations across software engineering, artificial intelligence, computer performance, operating systems, and modern computing technologies.

## About This Repository

This repository is a long-term technical reference rather than a collection of unrelated tutorials. It keeps research organized, makes progress visible, and provides a stable home for evidence, experiments, and conclusions as each topic is explored.

## Learning Approach

The intended rhythm is one topic per week: define the questions, study trustworthy sources, run experiments when useful, document the evidence, and clearly separate established facts from experimental observations and personal conclusions.

## Repository Structure

The repository contains 14 numbered category directories. Each category contains 10 numbered topic directories. Topic directories begin as empty placeholders and receive documentation only when work on that topic starts. A `.gitkeep` marker is present solely because Git does not track empty directories.

## Status Definitions

- **Not Started** — No research has been documented yet.
- **In Progress** — Research or experimentation is underway.
- **Explored** — A useful research summary has been completed.
- **Experimented** — The topic includes a documented, reproducible experiment.
- **Deep Dive** — The topic has received extensive analysis and validation.

## Standalone Projects

Mini-projects that demonstrate sufficient technical depth or practical value may later receive separate repositories linked from this knowledge base. No standalone projects are created in advance.

## References and Research Ethics

Sources should be cited accurately, experiments should be reproducible, and established facts must remain clearly distinguishable from experimental observations and personal conclusions. Topics are never marked complete without supporting evidence.
